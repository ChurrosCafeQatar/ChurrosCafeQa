# Local SEO Strategy

## The Four Active Locations
1. **Lusail** (Lusail Night Market)
2. **Abu Hamour** (Wadi Al Ghadeeriyat Street)
3. **Duhail** (Destination Box)
4. **Downtown** (Downtown Night Market)

## Branch SEO Rules
- Each branch has a dedicated URL (`/locations/[branch]/`).
- Each branch page features unique meta titles and descriptions avoiding duplicated template strings. Example: "Churros Cafe Lusail | Churros, Desserts & Coffee".
- Unique descriptive paragraphs per branch reflecting their neighborhood setting.
- `CafeOrCoffeeShop` JSON-LD schema injected automatically via `SchemaMarkup.tsx`.

## NAP Strategy (Name, Address, Phone)
- All NAP data originates from a strictly typed TypeScript dictionary in `data/content.ts`.
- Changes in this file automatically sync across the Locations Hub, Branch detail pages, and LocalBusiness JSON-LD structure ensuring complete consistency.

## GBP (Google Business Profile) Recommendations
- Ensure GBP listing URLs point directly to branch URLs rather than the homepage.
  - Recommended Lusail URL: `https://churroscafeqa.com/locations/lusail/?utm_source=google&utm_medium=organic&utm_campaign=gbp_lusail`
- Ensure Google Business Profile names match the exact schema output (e.g. `Churros Cafe Lusail`).

## Mall of Qatar Closure Handling
- The Mall of Qatar branch is permanently closed.
- It has been completely scrubbed from `CHURROS_CAFE.branches`, meaning it will not appear in the active locations directory, active branch count, or `ItemList` schema.
- To preserve user experience and historical search equity, visiting `/locations/mall-of-qatar/` returns a `200 OK` status with a dedicated static "Permanently Closed" view generated by `app/[...slug]/page.tsx`.
- The closed page prominently navigates users to the Locations Hub.
- The closed page deliberately lacks LocalBusiness JSON-LD schema to prevent conflicting search engine directives.
